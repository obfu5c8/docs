# Services

Each page describes a service independent of the host that currently runs it. All currently documented services are hosted on [[Infrastructure/Hosts/Firebat|Firebat]].

- [[Services/Ingress|Ingress]] — Nginx HTTPS and TCP routing boundary.
- [[Services/Syncthing|Syncthing]] — vault synchronization peer.
- [[Services/Monitoring|Monitoring]] — metrics, logs, dashboards, probes, and alerts.
- [[Services/Smart home|Smart home]] — Home Assistant, MQTT, Zigbee2MQTT, InfluxDB, Grafana, and Matter.
- [[Services/UniFi|UniFi]] — controller and MongoDB.
- [[Services/Cook|Cook]] — recipe application and PostgreSQL.
- [[Services/DNS|DNS]] — declarative management of ingress CNAME records.
